# Bam Together

WoW addon that plays a BAM sound on critical hits and shares it with your party. Based on [Bam! Forever](https://www.curseforge.com/wow/addons/bam-forever/comments) by Fedex1991.

The addon lives in [`BamTogether/`](BamTogether/), see its [README](BamTogether/README.md) for features, installation and commands.
